# Uluslararasi Asansor Sessizlik ve Nefes Tutma Olimpiyatlari

Bu depo, asansor icinde konusmamayi bir spor dalina ceviren resmi protokol yazilimidir.

Bilim insanlari yillardir su soruyu sormaktadir: *Asansorde iki yabanci neden aniden tavanı inceler?* Cevap basittir. Cunku olimpiyat baslamistir.

## Nasil calisir?

```bash
python olimpiyat.py
```

Program sizi rastgele bir kata gonderecek, kapi kapanacak ve nefes tutma suresi baslayacaktir. Konusursaniz diskalifiye olursunuz. Oksijen bitince de diskalifiye olursunuz. Kısaca hayat.

## Kurallar

1. Asansor kapi acilinca selam vermek yasaktir.
2. "Hangi kata?" diye sormak olimpiyat sucudur.
3. Ayna varsa kendinize bakabilirsiniz ama gulumsemek puan kaybettirir.
4. Müzik acilirsa kulaklarinizi kapatmak serbesttir, cunku o muzik genellikle bir cezadir.

## Teknik detaylar

- Dil: Python 3
- Bagimlilik: sadece standart kutuphane (asansorler de oyle olmali)
- Test edilmistir: hayir, henuz kimse nefesi yetiremedi
